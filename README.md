# Campus La Mar

## Descripción

Campus La Mar es una plataforma web académica diseñada para ofrecer un espacio de información y acceso a la comunidad educativa.

Este proyecto forma parte de un proyecto académico de Desarrollo de Aplicaciones Web (DAW).

## Funcionalidades actuales

- Página principal responsive.
- Navegación entre secciones.
- Pantalla de acceso.
- Validación básica del formulario de acceso.
- Componentes reutilizables para cabecera y pie de página.

## Documentación

La documentación del proyecto está organizada en las siguientes secciones:

- `01-analisis/`: análisis inicial del proyecto.
- `02-requisitos/`: requisitos funcionales y no funcionales.
- `03-diseño/`: diseño e identidad visual.
- `04-planificación/`: planificación y organización del trabajo.
- `05-testing/`: pruebas y validaciones.
- `06-memoria-final/`: documentación final del proyecto.

## Instalación

1. Clonar el repositorio.
2. Configurar un servidor web compatible con PHP.
3. Colocar o configurar la carpeta `frontend/` dentro del directorio público del servidor.
4. Acceder a la aplicación desde el navegador.
